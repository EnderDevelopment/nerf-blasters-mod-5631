# Nerf Blasters Mod

Add Nerf blasters and darts to your Minecraft world

## Features

- Adds Nerf blasters as a new item
- Adds Nerf darts as a new item that can be shot from blasters

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher
- Java 17 or higher

## Installation

1. Download the mod JAR file from the releases page
2. Place the JAR file in your Minecraft mods folder
3. Launch Minecraft with the Fabric profile

## Usage

1. Craft a Nerf blaster using the appropriate recipe
2. Craft Nerf darts
3. Load the Nerf blaster with darts and shoot them at entities

## Configuration

The mod does not have any configuration files. All settings are hardcoded in the mod.
